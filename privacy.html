개인정보처리방침

Gold Digger Archive는 개인 운영자의 Google Drive를 이용해 로컬 시장 데이터를 보관합니다.

접근하는 데이터와 사용 목적

  • Google 계정 이메일: 운영자가 지정한 계정인지 확인합니다.
  • 저장용량 정보: 보관 파일을 저장할 여유 공간이 있는지 확인합니다.
  • 앱이 생성하거나 사용자가 앱에 허용한 Drive 파일·폴더의 내용과 메타데이터: 보관 폴더 생성, 업로드, 중복 점검, 다운로드 검증 및 복원에 사용합니다.
  • OAuth 인증 토큰: 사용자가 승인한 Drive 접근을 유지하는 데 사용합니다.

접근 범위는 Google의 drive.file 권한입니다. 계정 전체의 문서 내용을 검색하지 않으며 Gmail이나 Google 포토의 내용에는 접근하지 않습니다.

저장 위치와 보호

시장 데이터 묶음은 운영자의 Google Drive 전용 폴더에 저장합니다. 인증 정보와 처리 상태·검증 기록은 운영자의 맥에 저장합니다. 인증 파일은 해당 사용자만 읽고 쓸 수 있는 권한으로 관리하며 공개 소스 저장소와 이 홈페이지에 포함하지 않습니다.

Google Drive와 통신할 때 암호화된 HTTPS 연결을 사용합니다. Google 비밀번호는 Google 로그인 화면에서만 처리하며 이 프로그램이 수집하지 않습니다.

공유와 사용 제한

인증으로 얻은 Google 사용자 데이터는 보관 기능에 필요한 용도로만 사용합니다. 보관 파일을 공개하거나 다른 사용자에게 자동 공유하지 않습니다. Google 사용자 데이터를 판매하지 않으며 광고, 신용 평가 또는 일반 AI 모델 학습에 사용하지 않습니다.

Google API에서 받은 정보의 사용 및 다른 앱으로의 전달은 Google API Services User Data Policy의 Limited Use 요건을 따릅니다.

보관 기간·삭제·동의 철회

Drive의 보관 파일은 운영자가 직접 삭제할 때까지 유지합니다. 로컬 원본은 업로드 및 다운로드 검증을 마치고 운영자의 보관 조건을 충족한 경우에만 정리합니다. 실패가 발생하면 원본을 보존합니다.

Google 계정의 연결 관리에서 앱의 접근 권한을 취소할 수 있습니다. 앱을 완전히 종료하려면 로컬 보관 스케줄러를 해제하고 로컬 인증 파일을 삭제합니다. Drive에 저장된 보관 파일은 운영자가 Drive에서 삭제할 수 있습니다. 권한 취소가 이미 보관된 파일을 자동 삭제하지는 않습니다.

안내 홈페이지

이 홈페이지에는 로그인, 입력 양식, 광고 또는 별도의 분석 스크립트가 없습니다. 호스팅 제공자인 GitHub는 보안 목적으로 방문자의 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.
